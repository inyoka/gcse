# Common Python Examples

This folder contains Python code examples that are applicable to **both AQA and OCR** GCSE Computer Science specifications.

## Topics Covered

| Folder | Description |
|--------|-------------|
| `string-manipulation/` | String methods, slicing, and formatting |
| `maths/` | Mathematical operations and random numbers |
| `real-world-examples/` | Practical programming projects |

## Why These Are Common

Both AQA and OCR exam boards share many core programming concepts. The examples here demonstrate:

- Standard Python techniques used in both specifications
- Practical programming skills that apply to any GCSE course
- Real-world applications that make learning engaging

## Using These Examples

These examples are designed to be:
- **Beginner-friendly**: Clear comments and simple explanations
- **Practical**: Real-world scenarios that students can relate to
- **Extensible**: Starting points for larger projects

## Contributing Common Examples

When adding examples to this folder:
1. Ensure the topic is covered by both AQA and OCR specifications
2. Use clear, GCSE-appropriate coding style
3. Include comprehensive comments
4. Add test cases where appropriate
