# AQA GCSE Computer Science - Python Examples

This folder contains Python code examples specifically aligned with the **AQA GCSE Computer Science (8525)** specification.

## Topics Covered

The examples in this folder are organised according to the AQA specification:

| Folder | Topic | Specification Reference |
|--------|-------|------------------------|
| `fundamentals/` | Programming fundamentals | 3.2.1 |
| `control-flow/` | Selection and iteration | 3.2.2 |
| `data-structures/` | Arrays and data structures | 3.2.3 |
| `subroutines/` | Subroutines and functions | 3.2.4 |
| `file-handling/` | File handling operations | 3.2.5 |
| `algorithms/` | Searching and sorting | 3.2.7 |
| `sql/` | SQL queries with Python | 3.2.8 |

## Using These Examples

Each Python file includes:
- A docstring explaining the concept being demonstrated
- Comments to help you understand the code
- Example usage that you can run and modify

## Contributing AQA Examples

When adding examples to this folder:
1. Check that the code aligns with the AQA specification
2. Place the file in the correct topic subfolder
3. Include the specification reference in your docstring
4. Test your code before submitting
