# Contributing to GCSE Python Code

Thank you for your interest in contributing to this repository! Whether you're a teacher, student, or Python enthusiast, your contributions help make this a valuable resource for GCSE Computer Science.

## How to Contribute

### For Students

1. **Fork this repository** to your own GitHub account
2. **Clone your fork** to your local machine
3. **Create a new branch** for your contribution
4. **Add your code** following the guidelines below
5. **Submit a pull request** with a clear description

### For Teachers

Teachers are encouraged to contribute:
- Code examples used in lessons
- Solutions to common programming tasks
- Exam-style practice questions and solutions

## Code Guidelines

### File Naming
- Use lowercase with underscores: `bubble_sort.py`
- Be descriptive: `input_validation.py` not `task1.py`
- Include difficulty if relevant: `recursion_advanced.py`

### Code Format

Every Python file should include:

```python
"""
Topic: [Topic Name]
Exam Board: AQA / OCR / Both
Specification Reference: [e.g., AQA 3.2.1 or OCR 2.2.1]
Difficulty: Foundation / Higher / Both

Description:
Brief explanation of what this code demonstrates.
"""

# Your code here with clear comments

# Example usage
if __name__ == "__main__":
    # Demonstrate the code
    pass
```

### Coding Style

- Write clear, readable code suitable for GCSE students
- Use meaningful variable names
- Include comments explaining key concepts
- Follow PEP 8 style guidelines where practical
- Keep examples focused on one concept at a time

### Testing Your Code

Before submitting:
1. Ensure your code runs without errors
2. Test with sample inputs
3. Check that comments are accurate
4. Verify file is in the correct folder

## What to Contribute

### We Welcome

- ✅ Code examples demonstrating GCSE topics
- ✅ Past paper solutions (with proper attribution)
- ✅ Bug fixes and improvements
- ✅ Documentation improvements
- ✅ Real-world programming examples

### Please Avoid

- ❌ Code copied from copyrighted sources without permission
- ❌ Overly complex code beyond GCSE level
- ❌ Code without comments or documentation
- ❌ Files in wrong folders or with unclear names

## Pull Request Process

1. **Describe your changes** clearly in the PR description
2. **Reference** any related issues or exam board specifications
3. **Wait for review** from maintainers
4. **Address feedback** if changes are requested
5. **Celebrate** when your contribution is merged! 🎉

## Questions?

If you're unsure about anything, please:
- Open an issue to discuss your contribution idea
- Ask in the pull request for guidance
- Check existing examples for reference

## Code of Conduct

- Be respectful and constructive
- Help others learn
- Give credit where it's due
- Keep content appropriate for educational settings

Thank you for helping to build this learning resource!
