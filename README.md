# GCSE Python Code Reference

A collection of Python code examples and solutions commonly used in GCSE Computer Science exams for the **AQA** and **OCR** exam boards.

## Purpose

This repository serves as a reference for GCSE-level Python programming concepts, including:

- Input and output
- Variables and data types
- Selection (if/elif/else statements)
- Iteration (for and while loops)
- Lists and arrays
- Functions and procedures
- File handling
- String manipulation
- Error handling

## Contributing

**We encourage teachers and students to contribute!**

If you have Python code examples, exam-style solutions, or helpful snippets that could benefit others studying for their GCSE Computer Science exams, please consider submitting your code.

### How to Contribute

1. **Fork** this repository
2. **Create** a new branch for your contribution
3. **Add** your Python code with clear comments explaining what it does
4. **Submit** a pull request with a description of your contribution

### Contribution Guidelines

- Ensure your code is well-commented and easy to understand
- Include a brief description of what the code demonstrates
- Indicate which exam board (AQA/OCR) the code relates to, if applicable
- Test your code before submitting to ensure it runs correctly
- Keep examples focused on GCSE-level concepts
