# Past Paper Solutions

This folder contains Python solutions to past paper programming questions from AQA and OCR GCSE Computer Science exams.

## Structure

```
past-papers/
├── aqa/
│   ├── 2023/
│   ├── 2022/
│   └── 2021/
└── ocr/
    ├── 2023/
    ├── 2022/
    └── 2021/
```

## Using These Solutions

### For Students
1. **Try First**: Always attempt the question yourself before looking at solutions
2. **Compare**: Check your approach against the solution
3. **Learn**: Understand different ways to solve the same problem
4. **Practice**: Use solutions as templates for similar problems

### For Teachers
1. **Mark Schemes**: Reference for marking student work
2. **Teaching**: Demonstrate different approaches in class
3. **Discussion**: Compare student solutions with these examples

## Contributing Solutions

When adding past paper solutions:
1. Place in the correct exam board and year folder
2. Name files clearly: `q1_variables.py`, `q3_algorithm.py`
3. Include the standard header with exam details
4. Add comments explaining key steps
5. Follow mark scheme requirements where possible

## Disclaimer

- Solutions are provided by contributors and may not be official mark scheme answers
- Multiple valid solutions may exist for any given question
- Always check against official mark schemes for assessment purposes
