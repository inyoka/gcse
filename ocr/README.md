# OCR GCSE Computer Science - Python Examples

This folder contains Python code examples specifically aligned with the **OCR GCSE Computer Science (J277)** specification.

## Topics Covered

The examples in this folder are organised according to the OCR specification:

| Folder | Topic | Specification Reference |
|--------|-------|------------------------|
| `fundamentals/` | Programming fundamentals | 2.2.1 |
| `control-flow/` | Selection and iteration | 2.2.2 |
| `data-structures/` | Arrays and data structures | 2.2.3 |
| `subroutines/` | Functions and procedures | 2.2.4 |
| `file-handling/` | File handling operations | 2.2.5 |
| `algorithms/` | Searching and sorting | 2.2.6 |
| `robust-programs/` | Input validation and testing | 2.2.7 |

## Using These Examples

Each Python file includes:
- A docstring explaining the concept being demonstrated
- Comments to help you understand the code
- Example usage that you can run and modify

## Contributing OCR Examples

When adding examples to this folder:
1. Check that the code aligns with the OCR specification
2. Place the file in the correct topic subfolder
3. Include the specification reference in your docstring
4. Test your code before submitting
